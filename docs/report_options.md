# Report Options

## Report Options
The user can select which information shall be given in the report using the corresponding "Report Options" dialog. This dialog can be opened by clicking the corresponding button  at the bottom of the report dialog window.
Using the checkboxes, the user can decide which of the following information shall be included in the Report:
Licensee
|
The name of the licensee of the software (as given in the licence file) is printed
at the top of the report if this option is active.
|
Sample data
|
Any information that is currently present about your sample, like collection data, number of data points, wavelength of radiation etc.
|
Matched phases list
|
List of all entries ("phases") the user has selected as matching. You can select if a summary shall be given,
if the phase as well as the elemental composition shall be displayed as pie charts, as well as which entry data shall be included in this matching phases tables (like formula sum, entry number etc.).
|
Candidates
|
List of all entries ("phases") in the candidate list which have not been selected by the user as matching. The maximum number of entries that shall be included in the list can be defined using the corresponding slider to the right of this option.
|
Search-match settings
|
The parameters and settings which have been used in the search-match calculation.
|
Peak list
|
A list of all peaks in the unknown sample's diffraction pattern, along with the matching phases they have been assigned to.
|
Restraints
|
If you have applied any restraints, the corresponding "search string" will be given.
|
Integrated profile areas
|
The calculated intensity integrals of the following profile areas are given: Overall diffraction profile,
background radiation, diffraction peaks, peak area belonging to selected phases, and
unidentified peak area. For each profile area, the integrated counts as well as the relative amount is given.
|
Peak residuals
|
The calculated peak intensities are given: Overall peak intensity, peak intensity belonging to selected phases, and
unidentified peak intensity (residuals). For each peak data type the summed peak intensiy (counts) as well as the relative amount is given.
|
Pattern graphics
|
The pattern graphics will be included; the width of the graphics (in pixels) can be adjusted using the slider. The default value of 640 pixels is appropriate for print on A4/portrait paper.
|
Save as defaults
|
If you mark this option, the current settings will be used again next time a report is created.
|
In the Pictures in report header section you can select graphics files (e.g. logos) to be
displayed to the left and/or right of the report header. In order to do so, please press the
corresponding Modify button, select the graphics file you would like to display, and finally
press "Open".
In order to remove a graphics file from being displayed, please click on the corresponding Delete
button.
In order to make the selection of one or two graphics files (as well as the remaining options) permanent,
you have to mark the Save as defaults box at the bottom left before closing the dialog by "OK".
