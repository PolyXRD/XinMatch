# Import User Database Entry(s)

## Import User Database Entry(s)
Using the "Import" button/command at the top of the User Database Manager,
you can import complete entries into the user database. If applicable, this is an efficient alternative to the
somewhat tiresome manual entering of entries.
After having pressed the "Import" button, you will be asked which type of file(s) you would like to import:
-  Crystal structure data (CIF) files (automatic calculation of the diffraction pattern, I/Ic and density)
- Match! user database files (*.mtu), e.g. obtained from a colleague
