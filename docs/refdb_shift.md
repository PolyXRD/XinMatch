## Shift PDF-2 Reference Database
If the reference database that is currently marked in the Reference
Database Library contains a PDF-2 database in the �old� format, you can shift (move) the
corresponding PDF-2 database file to a new location:
First, please display the Reference Database Library in Match!, e.g. by running the
"Select Reference Database" command from the "Database" menu. Afterwards, please move or copy
the corresponding file �pdf2.dat� (or similar) to the new
location (e.g. using the Windows Explorer, Finder or some other file manager), then press
the "Shift" button in the Reference
Database Library, and select the file �pdf2.dat� at the new location. Match! will
update the internal reference to this file, so that it knows where to find it when
reading data e.g. for displaying them in an entry data sheet.
