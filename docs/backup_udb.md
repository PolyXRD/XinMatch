# Save User Database

## Save User Database
Using the "Save" command in the User Database Manager, you can save the user
database that is currently in memory to a so-called "Match! user database" file (extension *.mtu). This mtu-file
can then be selected in the Create Reference Database dialog to create a new
Match! reference database from.
Please note:
- This command is also useful to create backup copies of your user data.
- The mtu-file created by this command
can be read later on using the "Open" command/button in the User Database Manager.
