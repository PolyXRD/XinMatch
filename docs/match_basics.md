# Match! Basics

## Match! Basics
Match! is a program for phase analysis using powder diffraction data. After program startup in the default "Beginner" mode, Match! will automatically try to run a qualitative and (semi-) quantitative analysis (; see below).
In the Match! window, the main tasks are rapidly available as buttons with a yellow background in the center of the main toolbar at the top:
- : Run a quick qualitative and (semi-) quantitative phase analysis
- : Perform a Rietveld refinement calculation (in combination with FullProf) ('FP' means 'FullProf')
- : Crystallite size estimation
- : Degree of crystallinity analysis
- : Raw data processing of raw/profile powder diffraction data, to get peak positions, intensities and peak widths (FWHM values)
- : Indexing (unit cell determination; in combination with Dicvol or Treor)
- : View or print the analysis Report
With most of these buttons/commands, Match! will take care about any data or information that may be required automatically: If Match! cannot perform a certain task automatically (like the selection of restraints or matching phases) and "Guided operations" have been activated on the "General" page of the "Options" window (which is the default setting), you will be given detailed instructions in a new window and then be asked to manually accomplish the task. When you have finished, you can indicate this by pressing a corresponding "Confirm" button.
"Guided operations" are active when using the default "Beginner" user level. If you are using a different user level (maybe "Expert"), you can activate them on the "General" page of the "Options" window.
What you can also do with Match!:
- Search the reference database (apply restraints)
- Pattern decomposition (Le Bail method) (in combination with FullProf)
- Crystal structure solution (along with Endeavour)
- Use other reference databases (e.g. any ICDD PDF database)
- Create and apply a User Database
- Repeating similar analyses
- Controlling Match! using script files

Remarks:
- Match! provides an undo/redo facility. You can undo nearly any operation until you return to the new empty Match! document where you started. On the other hand, you can also return to the state before you executed the "undo" command(s) using "redo". You should use these options extensively in order to try different options!
- In addition to the menus, context menus and the toolbar buttons, you can also use a variety of keyboard shortcuts to perform the most common operations.
Once you know these shortcuts by heart, your work will become much faster and more efficient.
